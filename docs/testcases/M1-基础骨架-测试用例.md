## 4. 已知限制与后续承接

1. 搜索为 SQL LIKE（万级 < 500ms 达标；如压测超限，M5 引入 FTS5）；
2. 列表虚拟滚动未启用（先分页+滚动加载，M5 压测不达标时启用，规划 8.4）；
3. 「加入复习」「导出」按钮已占位，M3/M4 接通；
4. 备份/恢复入口 M4 落地；LAN 监听开关需配合后端 host 配置重启生效。
