## 1. 环境与前置条件

- 后端：Python ≥ 3.12，`pip install -r backend/requirements.txt`
- 前端：Node ≥ 20，`npm install`
- 数据库：首次启动自动执行 Alembic 迁移（0001_initial）并种子内置学科
- 测试数据目录：pytest 使用临时目录（`RECALL_DATA_DIR` 隔离），不影响真实 data/

## 4. 已知限制与后续里程碑承接

1. 各页面当前为路由壳，完整功能在 M1~M5 落地；
2. `Auth/verify-token` 登录限流为进程内实现，单机场景够用（M5 复核）；
3. ChromaDB 未安装时向量检索自动降级，M3 复习检索时验证降级路径；
4. Alembic 0001 基线迁移以模型元数据建表，后续结构变更需新增带脚本的迁移（开发规划 5.3）。
