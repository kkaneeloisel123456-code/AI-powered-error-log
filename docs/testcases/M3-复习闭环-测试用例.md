## 1. 环境与前置条件

- mock 模式（AI/OCR）；已存在至少 1 道错题（POST /mistakes）
- 新错题默认次日进入复习计划（M3 起生效）

## 4. 已知限制与后续承接

1. 题目检索的「向量相似度」暂以薄弱加权兜底（规划 8.4 降级路径）；ChromaDB 接入点为 review_service._retrieve_mistakes；
2. 换题语义：换一题保持 variant_id 稳定（前端作答引用不变），内容重新生成；
3. 已掌握判定需「连续 2 次 q≥4 且间隔 ≥30 天」，30 天间隔在 MVP 周期内难触发，逻辑已实现并由 M4 看板掌握状态可视化验证；
4. AI 批改真实模式依赖 DeepSeek JSON Schema（GRADING_PROMPT），mock 下用答案比对；
5. 复习专注舱为页面级切换，M5 答疑页接入。
