## 4. 已知限制与后续承接

1. 聚合缓存 TTL 15s + 复习完成时失效（invalidate_cache 入口已留）；压测验证见 M5；
2. 共现边依赖多知识点题目（MVP 单 kp 模型），图谱当前仅父子层级边；
3. 恢复备份需重启服务（SQLite 文件替换语义），前端已提示；
4. PDF 导出为打印排版页（浏览器「另存为 PDF」），满足 A4 纸感样式与预览要求；
5. ECharts 主包体积偏大（chunk 警告），M5 加 manualChunks 拆分。
