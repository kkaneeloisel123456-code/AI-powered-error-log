## 4. 已知限制与后续承接

1. OCR/AI 为 mock 模式；接入 PaddleOCR-VL 时配置 RECALL_OCR_MOCK=false 与 PaddleX HTTP 服务地址（ocr/client.py），AI 拆题自动切换 DeepSeek JSON Schema 输出；
2. 压缩策略：>10MB 降分辨率转 JPEG 后仍超限才拦截（EX-02 前端压缩承诺）；
3. HEIC 转码依赖浏览器能力（Safari 原生支持），其余浏览器按不支持格式提示；
4. OCR 任务单机串行队列在 M5 压测验证（20 并发，PRD 7.9-27）。
